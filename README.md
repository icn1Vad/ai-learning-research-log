## How these notes are written

- The lab year and article publication date are separate.
- Archived results are distinguished from edited code examples and proposed follow-up checks.
- Source reports stay private; public notes omit identifiers, addresses, credentials, and unreviewed screenshots.
- Historical installation versions are not presented as current deployment recommendations.

These are records of learning and implementation, including constraints and failures. Planned projects and reference materials are not represented as completed research.
